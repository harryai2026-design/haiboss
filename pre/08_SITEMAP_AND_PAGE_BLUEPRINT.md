# 首版 Sitemap 与页面蓝图

## 首版范围：多页品牌官网

1. `/` 首页：品牌宣言、核心价值、痛点概览、AI 增效能力、电话 CTA。
2. `/pain-points.html` 传统外贸痛点：客户来源、找人、开发、知识沉淀、渠道成本与团队效率。
3. `/ai-growth.html` AI 增效能力：发现、判断、触达、承接、沉淀的工作闭环。
4. `/solutions.html` 服务场景：制造企业、传统外贸团队、经销商开发和多品类增长。
5. `/about.html` 海老板：品牌理念、服务原则、合作方式。
6. `/contact.html` 联系海老板：仅展示电话，不接入下单或支付。

辅助页面：`/404/`；如部署收集数据，再补隐私声明。

## 首页转化结构

问题与代价 → 适合谁/不适合谁 → 方法闭环 → 可交付成果 → 证据等级 → 方案入口（不先锁死价格）→ FAQ → 预约诊断。

## 内容原则

不展示价格、案例数字、认证、客户名称和效果承诺；只展示已确认的品牌定位与联系电话。
