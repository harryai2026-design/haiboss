本地验收用文章、询盘与相关发布任务在检查后清理；没有预建管理员账号。模板源包不包含开发数据库、询盘、媒体、日志、密钥、node_modules 或构建产物。详细机器可读结果位于本机 artifacts/verification（不打入模板包）。

Windows 中文路径的 PostgreSQL 启动通过项目专属 ASCII 目录联接处理，真实数据仍在本项目 `.local`；引用保存在 `.local/runtime-path.json`。静态版本用小型指针文件切换，避免监听目录改名问题。该运行记录不表示任何系统级服务已安装。

尚未验收：Linux 生产部署、CF/DNS、自动离机备份与恢复、真实通知供应商、付费 AI、多人/多租户业务与负载容量。多语言前台矩阵不替代新增语言后的数据库迁移验收。搜索、AI、报价和样品尚未集成，扩展步骤见 extensions.md。
