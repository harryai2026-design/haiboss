# 按业务扩展，不默认启动额外服务

产品目录、多语言和分析开关已实现。关闭产品时无后台入口、无产品 API、无产品前台路由；既有表数据保留，避免开关导致数据删除。关闭询盘时不启动接收进程，也不暴露联系表和导入端点。

## 搜索

少量内容优先前台过滤或静态搜索索引。真正需要全文检索时，新增 `modules/search`，由发布内容同步可重建索引。只有启用该模块的部署才增加 Meilisearch 等服务。索引不能成为主数据源，也不能索引草稿或客户询盘。

## AI 与自动翻译

默认没有模型密钥、收费调用或 MCP 服务。需要时新增具有范围、有效期、审计和预算限制的适配器；默认只读，内容写入先存草稿，正式发布由后台确认。各执行端凭据独立绑定。

## 报价与样品

保留询盘阶段和内部备注，通用报价/样品对象暂未移入模板。业务需要时新增独立集合，与询盘/产品关联，定义版本、不可变报价快照、附件权限和负责人，再生成迁移。报价不自动发送，不等同订单和支付系统。

## 询盘通知

当前「已接收」表示磁盘落盘/后台入库，不表示邮件或消息已经发出。需要通知时增加数据库持久化 outbox，在询盘事务提交后由后台 worker 发送；使用请求幂等标识、重试、失败状态与费用上限。不要在客户提交的 HTTP 请求内同步等待邮件供应商，也不要把密钥放前台。

## 多语言与统计

`config/site.json` 可选择内容语言；增删语言后需生成并验证数据库迁移。前台的缺译正文不会回退成错误语言。新语言的导航与表单界面当前回退英文，需要按市场补充翻译。

GA4 开关开启后也不会立即加载脚本。宿主项目完成适用的同意流程后，调用 `document.dispatchEvent(new Event('site:analytics-consent'))`。模板不提供默认同意或未经配置的自动追踪。
